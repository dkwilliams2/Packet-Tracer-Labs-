# Networking Labs

Hands-on Cisco networking labs from my coursework (CCNA topics). Each lab has its own folder with a README covering the topology, configuration, verification, and what I learned or troubleshot.

| Lab | Tools | Topics |
|-----|-------|--------|
| [Network Segmentation](network-segmentation/) | Cisco Packet Tracer | Subnetting, inter-subnet routing, troubleshooting a misplaced host |
| [Switch VLANs](switch-vlans/) | EVE-NG, VPCS | VLANs, access ports, 802.1Q trunking |
| [SSH Remote Management](ssh-remote-management/) | Cisco Modeling Labs | SSH v2, RSA keys, local accounts, switch management SVI, default gateway |
